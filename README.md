# 个人知识库

私有仓库，纯云端维护。**不 clone 到本地**——工作电脑磁盘加密，clone 下来的文件会变成密文。

技能库在另一个仓库：https://github.com/chengcan891/AI

## 我要记东西

打开 `raw/` 下当月文件，最后加一行。不分类、不美化、不管格式，一行就够。

值得记的只有三类：**决策**（选了什么、为什么）、**事故**（出了什么、根因）、**纠正**（谁说我哪里错了）。只此一次的、搜得到的、不会忘的，都别写。

## 我要让它整理

新开一个任务，把这句话发给它：

```
读 https://github.com/chengcan891/Knowledge 的 AGENTS.md，按「编译」那一节执行
```

**这句话必须带。** 因为新任务里没有之前聊过的任何内容，不提 AGENTS.md，它就只能反问你"你想怎么整理"，你就得每次重新解释一遍。规则全在 AGENTS.md 里，那句话等于把规则交给它。

编译完之后它会告诉你三件事：新建了哪几页、改了哪几页、丢掉了哪些碎片以及为什么丢。你只需要审，不用改。

## 三条红线

1. **不 clone 到本地**，只走网页和 API。
2. **`wiki/` 里不手改**。要改就跟 AI 说要改什么，它改完你审。手改一次，下次编译就会和你的版本打架。
3. **公司代码、需求原文、线上数据不进库**。只写抽象后的方法和理由，项目用代号。

## 隔一阵要确认一次

**技能库的定时密文检查会被自动停用。** GitHub 在仓库连续 60 天没有提交后关闭定时任务，且不发通知。每两三个月去 https://github.com/chengcan891/AI/actions 看一眼 `text-guard` 还在不在。

**AI 访问这个仓库用的 token 到 2026-11-30 过期。** 过期后的表现是：AI 说读不到仓库，或者报 404——注意不是 403，会让人以为是仓库被删了。碰上这种情况先去 https://github.com/settings/personal-access-tokens 重新生成一个（Repository access 选 All repositories，Contents 给 Read and write），再把新值交给 AI 更新配置。token 过期不会提前通知，所以到期前几天最好主动换掉。

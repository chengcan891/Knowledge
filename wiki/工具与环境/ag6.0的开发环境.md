# ag6.0 的开发环境

换电脑、或者接手这个项目时，照这张表重配。

| 环节 | 现在怎么做的 |
|---|---|
| 写代码 | Android Studio，配合 codex 和 cursor |
| 编译和启动 | 在 AS 里点 Run，不敲命令 |
| 装到设备 | USB 连 adb，直接推 |
| 跑在哪 | 安卓平板，不是手机 |
